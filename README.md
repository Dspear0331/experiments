A personal collection of standalone scripts and mini-automations built to solve specific developer tasks—regardless of the language.
About

This repository serves as a centralized space for quick hacks, workflow utilities, and proof-of-concept scripts. These are practical, functional tools created on the fly to eliminate everyday developer friction, automate repetitive tasks, and test out ideas in practice.
What's Inside

You will find a mix of languages and utilities, including:

    Bash / Shell: Environment setups, Git automations, and command-line shortcuts.

    Python / Others: Quick utilities and functional snippets built to handle specific logic or data tasks.
